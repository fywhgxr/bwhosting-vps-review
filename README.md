## 搬瓦工靠谱吗？从几个关键指标看

### 1. 会不会跑路：目前看，品牌连续性是加分项

BandwagonHost 的官网版权信息显示运营主体为 IT7 Networks Inc.，官网持续发布新机房、硬件和系统镜像更新。2025 年官方还发布过洛杉矶 USCA_9 新硬件上线的消息，并说明新实例会部署到新节点，已有实例可以通过 KiwiVM 查看升级选项。

这些信息不能证明未来绝对不会发生经营变化，但至少说明它不是刚上线几个月、靠低价吸引用户后就消失的小型服务商。对于需要长期保留服务器和数据的用户，这种运营连续性比一次性的低价优惠更重要。

不过，运营时间长不等于数据自动安全。VPS 仍然需要自己做异地备份，尤其是数据库、网站上传文件、SSH 密钥和配置文件。控制面板提供快照或备份功能，也不能替代独立备份。

### 2. 网络是否稳定：线路是搬瓦工最核心的卖点

BandwagonHost 官方把 CN2 GIA/CTGNet 线路定位为面向中国大陆访问场景的网络方案。官方说明，普通网络在高峰时段可能出现拥堵，而 CN2 GIA 的主要价值是改善中国大陆与美国之间的链路质量；同时，CN2 GIA 的成本更高、容量有限，也不适合承受大规模 DDoS 流量。

换句话说，搬瓦工贵的部分，主要买的是网络路径和机房资源，不是“同配置下拥有神奇的 CPU 性能”。

对于以下场景，优化线路可能更有意义：

- 面向中国大陆用户的个人网站；
- 需要从中国大陆访问的海外服务；
- 远程开发、代码仓库和管理后台；
- 跨境团队使用的轻量业务系统；
- 对晚高峰丢包和延迟比较敏感的应用。

但线路名称不能直接等于全年每时每刻都稳定。路由会变化，IP 可能受到封锁、黑名单或第三方过滤影响，用户本地网络也会影响最终体验。官方 SLA 文件同样明确排除了上游网络、第三方封锁、DDoS 攻击和 IP 被列入黑名单等情况。

### 3. 稳定性有没有保障：有承诺，但要看套餐类型和条件

官网首页展示了 99.9% 在线率保证和 30 天退款政策，但价格页和购物车中的具体产品可能显示不同的在线率条款。例如，标准 KVM 产品页面可以看到 99.95% uptime guarantee，而带有 E-Commerce+SLA 标识的套餐则提供更高等级的 SLA 说明。

这意味着不能只看到“99.99% SLA”就默认所有搬瓦工套餐都适用。官方 SLA 文件明确说明，SLA 只适用于明确标注为 SLA Plan 的 VPS，不适用于其他普通、免费、试用或促销服务。它还规定了计划维护、用户配置错误、资源限制、攻击、上游网络问题和法律合规等排除项。

判断时可以这样理解：

- 普通个人网站：标准 KVM 或 E-Commerce 套餐通常已经够用；
- 关键业务：应确认购买页面是否明确写有 SLA；
- 对停机赔偿有要求：需要阅读 SLA 的适用范围和申诉流程；
- 不能接受自己排查故障：VPS 本身就可能不适合你。

搬瓦工使用自研的 KiwiVM 控制面板。官方列出的功能包括开关机、系统重装、紧急控制台、rDNS 记录管理、机房迁移、快照、流量统计和 API 等。

1. 选择操作系统并重新安装；
2. 查看流量和资源使用情况；
3. 修改 rDNS；
4. 在支持的机房之间迁移 VPS；
5. 使用紧急控制台处理 SSH 无法连接的问题；
6. 创建或恢复快照。

机房迁移是它比较实用的功能。假设某个节点对你的本地网络表现不好，可以尝试切换到其他可用位置，而不用重新购买一台服务器。官方表示，VPS 可以在数据中心之间迁移，并且不会丢失数据。

但 KiwiVM 不是托管运维服务。它能让你更方便地管理服务器，却不会替你配置 Nginx、数据库、防火墙、备份策略或网站安全。官网也明确把这类服务描述为 self-managed，也就是自主管理型 VPS。

## 搬瓦工有哪些需要提前接受的缺点？

### 价格不是市场最低

早期搬瓦工的低价套餐曾经很有吸引力，但现在不能再把它简单理解成“便宜 VPS”。如果你只需要一台普通海外服务器，其他供应商可能提供更低的月付价格。

搬瓦工的溢价主要来自：

- 面向中国大陆的优化线路；
- 多机房选择；
- KiwiVM 面板；
- 快照、迁移和重装等操作便利；
- 一定程度的品牌连续性。

如果这些功能对你没有实际价值，价格就可能显得偏高。

### 自主管理意味着你要自己负责

服务器上线后，系统更新、SSH 安全、面板配置、数据库备份、恶意登录、防火墙规则和应用故障，通常都需要用户自行处理。你不能把购买 VPS 理解成购买了一个已经配置好的网站。

适合新手的方式是从单一用途开始：先部署一个网站或一个开发项目，确认系统备份、域名解析和恢复流程都正常，再逐步增加服务。不要一上来就在 1 GB 内存的 VPS 上安装一堆面板、数据库、监控和代理组件，然后把卡顿归咎于“主机不靠谱”。

### 退款政策有明确限制

BandwagonHost 确实提供 30 天退款政策，但官方条款并不是“无条件试用 30 天”。退款通常要求订单是新购买而非续费，购买时间不超过 30 天，账户没有欠款或违规记录，IP 没有进入黑名单，流量使用低于月度配额的 10%，并且退款申请不能被认定为滥用。

其中两个条件尤其值得留意：

- IP 被列入黑名单时，官方条款可能不提供退款；
- 流量使用超过规定比例后，退款资格可能受到影响。

所以，购买后可以尽快完成基础测试，但不要为了“测试速度”长时间跑大量流量，也不要等到套餐快到期才检查 IP、线路和应用是否正常。

### CN2 GIA 也不是 DDoS 防护

官方对 CN2 GIA 的说明很直接：这类线路容量有限，遭遇 DDoS 时可能需要对 IP 进行 null routing，也就是暂时丢弃或阻断相关流量。

因此，搬瓦工适合正常的网站、开发和远程服务，不适合把一台普通 VPS 当成抗攻击基础设施。如果你的业务容易遭遇攻击，应单独设计 CDN、清洗、备用节点和故障切换方案。
